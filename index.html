🧪 A Pirâmide e os 4 Níveis de Teste

            

                
                    

                        Nível
                        Foco Principal
                        Dependências
                        Comando Pytest
                    

                
                
                    

                        Unitário
                        Regras de cálculo, descontos e validação de quantidade.
                        Mocks / Stubs
                        pytest -m unit -v
                    

                    

                        Integração
                        Comunicação Estoque ↔ Carrinho ↔ Pagamento e Rollback.
                        Objetos Reais
                        pytest -m integration -v
                    

                    

                        Sistema
                        Jornada do cliente E2E: catálogo, checkout e cancelamento.
                        Fluxo Completo
                        pytest -m system -v
                    

                    

                        Aceitação
                        Validação de critérios de negócio e requisitos BDD (Black Friday).
                        Critérios de Usuário
                        pytest -m acceptance -v
                    

                
            

        

    


    
    

        

            
💻 Comandos de Execução no Terminal

            

# 1. Instalar as dependências necessárias

pip install pytest pytest-cov


# 2. Executar todos os 4 níveis de teste

pytest -v


# 3. Executar cada nível individualmente por marcador

pytest -m unit -v

pytest -m integration -v

pytest -m system -v

pytest -m acceptance -v


# 4. Relatório detalhado de cobertura de código

pytest --cov=src --cov-report=term-missing
