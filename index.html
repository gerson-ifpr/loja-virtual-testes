🧪 A Pirâmide de Testes Completa

Cada nível de teste possui um objetivo pedagógico e técnico específico no ciclo de vida de desenvolvimento de software (QA):

Nível de Teste O que valida? Por que é realizado? Dependência de Estoque/Pagamento
1. Unitário Lógica interna de cálculo de totais, percentuais de desconto e validação de parâmetros de entrada. Garante que cada método individualmente funcione de forma determinística em milissegundos. Mocks / Stubs (Isolamento total)
1. Integração Comunicação entre componentes (Carrinho ↔ Estoque ↔ Pagamento) e Rollback de Estoque em falhas financeiras. Identifica bugs em transações concorrentes e inconsistência no estado dos dados. Classes Reais integradas
2. Sistema A jornada completa ponta a ponta (E2E): Catálogo $\rightarrow$ Carrinho $\rightarrow$ Pagamento $\rightarrow$ Estorno. Valida se todas as regras de negócio operam em harmonia como um ecossistema completo. Fluxo Completo integrado
2. Aceitação Critérios de negócio no formato BDD (Dado-Quando-Então), como campanhas promocionais de Black Friday. Garante que o software atende ao que o cliente final e o setor de negócios esperam. Critérios de Usuário (BDD)

💻 Execução dos Testes por Sistema Operacional

Escolha o seu sistema operacional abaixo para ver o passo a passo completo:

1
Instalar as dependências
PS C:\loja_virtual> python -m pip install -r requirements.txt
2
Executar todos os testes
PS C:\loja_virtual> python -m pytest -v
3
Executar testes específicos por nível
PS C:\loja_virtual> python -m pytest -m unit -v # Unitários
PS C:\loja_virtual> python -m pytest -m integration -v # Integração
PS C:\loja_virtual> python -m pytest -m system -v # Sistema
PS C:\loja_virtual> python -m pytest -m acceptance -v # Aceitação
4
Gerar e abrir relatório de cobertura de código no navegador
PS C:\loja_virtual> python -m pytest --cov=src --cov-report=html
PS C:\loja_virtual> start htmlcov\index.html

⚠️ Por que ocorre o erro "'pytest' não é reconhecido..."?

Explicação Técnica:
Quando você digita pytest, o sistema operacional procura um executável com esse nome nas pastas listadas na variável de ambiente PATH. Se a pasta Scripts (no Windows) ou ~/.local/bin (no Linux) não estiver no PATH, o sistema emite o erro de comando não encontrado.

🛠️ Como corrigir de forma definitiva no Windows:

1
Pressione as teclas Win + R, digite sysdm.cpl e pressione Enter.
2
Clique na aba Avançado e depois no botão Variáveis de Ambiente....
3
Em Variáveis de usuário, selecione a linha Path e clique em Editar....
4
Clique em Novo e cole o caminho da pasta de scripts do seu Python (ex: C:\Users\SEU_USUARIO\AppData\Local\Programs\Python\Python311\Scripts).
5
Clique em OK, feche e abra novamente o PowerShell.

🐧 Como corrigir no Linux / macOS:

No terminal do Linux ou macOS, adicione o diretório local de binários ao seu arquivo de perfil executando:
$ echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
$ source ~/.bashrc
